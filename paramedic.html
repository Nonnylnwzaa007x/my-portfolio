Overview

เกม VR จำลองสถานการณ์ฉุกเฉินทางการแพทย์ โดยให้ผู้เล่นรับบทบาทเป็นหน่วยกู้ชีพ (Paramedic) เข้าไปช่วยเหลือผู้บาดเจ็บ ณ จุดเกิดเหตุ ผู้เล่นจะได้เรียนรู้และปฏิบัติตามขั้นตอนการกู้ชีพจริง ทั้งการประเมินคัดแยกความรุนแรงของผู้ป่วย (Triage), การปฐมพยาบาลเบื้องต้น, การกดหน้าอกทำ CPR และการใช้วิทยุสื่อสารรายงานสถานการณ์

ในโปรเจกต์นี้ผมได้รับหน้าที่พัฒนาระบบ Gameplay และการตอบสนองในโลก VR (VR Interactions) ทั้งหมด เพื่อให้ผู้เล่นได้สัมผัสขั้นตอนการกู้ชีพที่สมจริงและใช้งานง่าย

Key Features

  • CPR Simulation: จำลองการทำ CPR ปั๊มหัวใจ โดยตรวจจับตำแหน่งมือและการทิ้งน้ำหนักตัว พร้อมคำนวณอัตราความเร็วการกด (BPM) แบบ Real-time
  • Triage System: พัฒนาระบบประเมินและคัดแยกผู้ป่วยตามระดับความเร่งด่วน พร้อมการติดแท็กริบบิ้นแยกสี (เขียว, เหลือง, แดง, ดำ) เพื่อส่งต่อการรักษา
  • Radio Communication: ระบบวิทยุสื่อสารจำลองที่ตรวจจับระยะ เมื่อผู้เล่นยกวิทยุขึ้นมาจ่อใกล้ปากและกดพูด จึงจะสามารถรายงานสถานการณ์ได้
  • VR Item Handling: ออกแบบการหยิบใช้อุปกรณ์ปฐมพยาบาลในกระเป๋าอย่างเป็นธรรมชาติ พร้อมระบบดึงไอเทมกลับเข้ากระเป๋าอัตโนมัติเมื่อทำหล่น

Challenges & Solutions

1. การจำลองการกดหน้าอกทำ CPR ในโลก VR

ปัญหา: อุปกรณ์ VR ไม่มีแรงต้านทานทางกายภาพ (Force Feedback) หากใช้การตรวจจับการชน (Collision) ทั่วไป มือจะกดทะลุตัวผู้ป่วย และไม่สามารถประเมินแรงกดรวมถึงจังหวะปั๊มหัวใจที่ถูกต้องได้
วิธีแก้: ออกแบบระบบ CPRController โดยผสานการตรวจจับตำแหน่งมือให้อยู่บนหน้าอก ร่วมกับการตรวจจับการโน้มตัวของผู้เล่น (ระยะการกดต่ำลงของ Headset) เพราะการทำ CPR จริงจะต้องทิ้งน้ำหนักตัวลง พร้อมคำนวณอัตราความเร็วการกด (BPM) แบบ Real-time และใส่ตัวป้องกันการนับซ้ำ (Debounce) 

// Biomechanical CPR Detection & Real-time BPM Calculation
float currentY = _headAnchor.position.y;
float drop = _baselineY - currentY;

if (drop >= _compressionDepth && !_isCompressing) {
    _isCompressing = true;
    float now = Time.time;
    float elapsed = now - _lastCompressionTime;
    if (elapsed < _minInterval) return; // Debounce ป้องกันนับซ้ำ

    _compressionCount++;
    float bpm = 60f / elapsed;
    _lastCompressionTime = now;

    if (bpm < 200f) {
        OnCompressionSuccess?.Invoke(bpm); // อัปเดตตัวเลขขึ้น UI Text
    }

    if (_compressionCount >= _requiredCompressions) {
        _isCompleted = true;
        OnCPRComplete?.Invoke(); // ผ่านเงื่อนไขกู้ชีพสำเร็จ
    }
}
else if (drop < _compressionDepth * 0.3f && _isCompressing) {
    _isCompressing = false;
    _baselineY = currentY; // รีเซ็ตความสูงเตรียมรับการกดรอบถัดไป
}

2. ระบบวิทยุสื่อสารที่ตรวจจับระยะปาก (Walkie-Talkie Interaction)

ปัญหา: การใช้ UI เมนูกดปุ่มทั่วไปทำให้เสียบรรยากาศและความสมจริงในสถานการณ์ฉุกเฉิน
วิธีแก้: พัฒนาระบบ WalkieTalkieController ตรวจจับเงื่อนไขเสมือนจริง: ผู้เล่นต้องหยิบวิทยุ (Grab), กดปุ่ม Push-to-Talk และ ยกวิทยุขึ้นมาใกล้ปาก (ตรวจจับระยะห่างกับ Headset ≤ 0.25m) จึงจะเริ่มส่งสัญญาณรายงานศูนย์สั่งการได้ พร้อมระบบดึงวิทยุกลับซองเหน็บเอวอัตโนมัติเมื่อปล่อยมือ 

// ตรวจสอบสถานะส่งสัญญาณวิทยุ (ต้องถือ + กด PTT + ยกจ่อใกล้ปาก)
bool isGrabMet = !_requireGrab || _isGrabbed;
bool isPttMet = !_requirePttButton || _isPttPressed;
bool isProximityMet = !_requireMouthProximity;

if (_requireMouthProximity && _centerEyeAnchor != null) {
    // ตรวจสอบระยะห่างระหว่างตัววิทยุกับ HMD (Center Eye)
    float distToMouth = Vector3.Distance(transform.position, _centerEyeAnchor.position);
    isProximityMet = distToMouth <= _mouthProximityThreshold;
}

if (isGrabMet && isPttMet && isProximityMet) {
    _transmissionTimer += Time.deltaTime;
    if (_transmissionTimer >= _requiredTransmissionTime) {
        OnTransmissionCompleted?.Invoke(); // ส่งรายงานสำเร็จ
    }
}

3. ระบบคัดแยกผู้ป่วยและการจัดการไอเทมใน VR (Triage & Item Handling)

ออกแบบระบบคัดแยกผู้ป่วย (Triage System) แบบแยกส่วน (Decoupled) เพื่อให้จัดการเคสผู้ป่วยและอุปกรณ์ปฐมพยาบาลได้หลากหลาย พร้อมเพิ่มระบบอำนวยความสะดวกในโลก VR หากผู้เล่นทำอุปกรณ์หล่นกลางอากาศ วัตถุจะเด้งกลับเข้ากระเป๋าพยาบาลโดยอัตโนมัติ ช่วยให้ผู้เล่นในงานนิทรรศการเล่นได้อย่างต่อเนื่อง โดยไม่ต้องก้มลงไปเก็บของบนพื้น
