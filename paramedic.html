Overview

ระบบ VR จำลองสถานการณ์ฉุกเฉินทางการแพทย์ โดยให้ผู้เล่นรับบทบาทเป็นหน่วยกู้ชีพที่ต้องทำงานแข่งกับเวลา โปรเจกต์นี้ต้องการความแม่นยำสูงในระบบประเมินผลและการใช้ State Machine ควบคุมลำดับเหตุการณ์ (Emergency Protocol) ให้สมจริง

Key Features

  • Scoring System: พัฒนาระบบประเมินผลผู้เล่นตามขั้นตอน Emergency Protocol ของจริง
  • Medical Equipment: สร้างระบบโต้ตอบกับอุปกรณ์ทางการแพทย์ในโลก VR (เช่น เครื่องกระตุกหัวใจ, อุปกรณ์ทำแผล)
  • UI & Atmosphere: ผสานระบบ UI แจ้งเตือนสถานะผู้ป่วยและเวลานับถอยหลัง ผสานกับระบบเสียงเพื่อสร้างความกดดันให้เหมือนสถานการณ์จริง

Challenges & Solutions

การโต้ตอบกับวัตถุที่ซับซ้อน: อุปกรณ์การแพทย์บางชิ้นมีหลายชิ้นส่วนที่ต้องประกอบกันและทำงานตามลำดับที่ถูกต้องในโลก VR ผมได้ออกแบบระบบ State Machine เพื่อจัดการสถานะของอุปกรณ์แต่ละชิ้น เพื่อให้ควบคุม Logic ได้ง่าย ป้องกันบัคจากการข้ามขั้นตอน และทำให้ใช้งานได้อย่างสมจริง

ตัวอย่างโค้ด: State Machine Pattern

public enum DeviceState { 
    Idle, 
    Charging, 
    Ready, 
    Discharging 
}

private DeviceState currentState = DeviceState.Idle;

public void ChangeState(DeviceState newState) {
    currentState = newState;
    switch (currentState) {
        case DeviceState.Charging:
            StartCoroutine(ChargeDevice());
            break;
        case DeviceState.Discharging:
            ApplyShockToPatient();
            ChangeState(DeviceState.Idle);
            break;
    }
}

ตัวอย่างโค้ด: Emergency Timer System

การสร้างความกดดันให้ผู้เล่นเป็นสิ่งสำคัญในเกมแนวนี้ ผมใช้ Coroutine สร้างเวลานับถอยหลังพร้อมอัปเดต UI และทริกเกอร์เสียงเตือน (Heartbeat Warning) เมื่อเวลาใกล้หมด เพื่อเร้าอารมณ์ผู้เล่น 

private IEnumerator EmergencyCountdown(float timeLimit) {
    float timeRemaining = timeLimit;
    
    while (timeRemaining > 0 && !isPatientStabilized) {
        timeRemaining -= Time.deltaTime;
        UpdateTimerUI(timeRemaining);
        
        // เล่นเสียงเตือนเมื่อเวลาเหลือน้อยกว่า 10 วินาที
        if (timeRemaining <= 10f && !audioSource.isPlaying) {
            PlayHeartbeatWarningSound(); 
        }
        yield return null;
    }

    // ถ้าเวลาหมดและผู้ป่วยยังไม่ปลอดภัย = Game Over
    if (!isPatientStabilized) {
        TriggerGameOverState();
    }
}
