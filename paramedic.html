Overview

ระบบ VR จำลองสถานการณ์ฉุกเฉินทางการแพทย์และอุบัติเหตุหมู่ (Mass Casualty Incident - MCI) โดยให้ผู้เล่นรับบทบาทเป็นนักปฏิบัติการฉุกเฉินการแพทย์ (Paramedic) ที่ต้องทำงานแข่งกับเวลา ณ จุดเกิดเหตุ โดยเน้นความสมจริงตามหลักการแพทย์สากล ทั้งการประเมินคัดแยกผู้ป่วย (START Triage Protocol), การปฐมพยาบาลเบื้องต้น, การกู้ชีพด้วย CPR และการรายงานสถานการณ์ผ่านวิทยุสื่อสาร

Key Features

  • Biomechanical CPR Simulation: จำลองการทำ CPR โดยคำนวณระยะกดหน้าอกจากระยะโน้มศีรษะ (Head Dip Depth) และตำแหน่งมือ พร้อมคำนวณอัตราความเร็ว Real-time BPM
  • START Triage System: วางโครงสร้างสถาปัตยกรรมแบบ Modular คัดแยกผู้ป่วย 4 ระดับ (สีเขียว: บาดเจ็บเล็กน้อย, สีเหลือง: บาดเจ็บปานกลางต้องปฐมพยาบาล, สีดำ: เสียชีวิต, สีแดง: วิกฤตฉุกเฉิน)
  • Natural VR Interactions (NUI): ระบบวิทยุสื่อสารจำลองการตรวจจับระยะปาก (Mouth Proximity) เพื่อพูดรายงานศูนย์ และระบบ Gaze Raycast จ้องมองเพื่อพรีวิวข้อมูลเคสผู้ป่วย
  • VR Ergonomics & QoL: ระบบเสกแท็กริบบิ้นไม่จำกัดในกระเป๋าพยาบาล (Infinite Dispenser) และระบบส่งของเด้งกลับกระเป๋าอัตโนมัติเมื่อทำหล่นกลางอากาศ

Challenges & Solutions

1. การจำลองการกดหน้าอกทำ CPR บน Standalone VR

ปัญหา: บน Standalone VR คอนโทรลเลอร์หรือ Hand Tracking ไม่มีแรงต้าน (No rigid pushback) หากใช้ Collision ปกติ ผู้เล่นจะก้มกดทะลุตัวผู้ป่วย และไม่สามารถประเมินแรงกดและจังหวะปั๊มหัวใจที่ถูกต้องได้
วิธีแก้: ออกแบบระบบ CPRController โดยผสานการเช็คตำแหน่งมือให้อยู่ในโซนหน้าอก ร่วมกับ Biomechanical Depth Tracking โดยตรวจจับระยะการโน้มตัวของศีรษะ (Head Anchor Dip ≥ 0.05m) เพราะเวลาคนทำ CPR จริงจะต้องทิ้งน้ำหนักตัวลง พร้อมคำนวณค่า Real-time BPM (60 / Δt) และใส่ Debounce ป้องกันการนับเบิ้ล 

// Biomechanical CPR Detection & Real-time BPM Calculation
float currentY = _headAnchor.position.y;
float drop = _baselineY - currentY;

if (drop >= _compressionDepth && !_isCompressing) {
    _isCompressing = true;
    float now = Time.time;
    float elapsed = now - _lastCompressionTime;
    if (elapsed < _minInterval) return; // Debounce ป้องกันนับซ้ำ

    _compressionCount++;
    float bpm = 60f / elapsed;
    _lastCompressionTime = now;

    if (bpm < 200f) {
        OnCompressionSuccess?.Invoke(bpm); // อัปเดตตัวเลขขึ้น UI Text
    }

    if (_compressionCount >= _requiredCompressions) {
        _isCompleted = true;
        OnCPRComplete?.Invoke(); // ผ่านเงื่อนไขกู้ชีพสำเร็จ
    }
}
else if (drop < _compressionDepth * 0.3f && _isCompressing) {
    _isCompressing = false;
    _baselineY = currentY; // รีเซ็ตความสูงเตรียมรับการกดรอบถัดไป
}

2. Natural User Interface (NUI): วิทยุสื่อสารที่ตรวจจับระยะปาก

ปัญหา: การใช้เมนู UI 2D ลอยกลางอากาศทำลายความสมจริงในสถานการณ์ฉุกเฉิน (Breaks Immersion)
วิธีแก้: พัฒนาระบบ WalkieTalkieController ที่ตรวจจับเงื่อนไขเสมือนจริง: ผู้เล่นต้องถือวิทยุ (Grab), กดปุ่ม PTT (Push-to-Talk) และ ยกวิทยุขึ้นมาใกล้ปาก (ตรวจจับระยะห่างกับ CenterEyeAnchor ≤ 0.25m) จึงจะเริ่มส่งสัญญาณรายงานศูนย์สั่งการได้ พร้อมระบบ Lerp ดึงวิทยุกลับซองเหน็บเอวอัตโนมัติเมื่อปล่อยมือ 

// ตรวจสอบสถานะส่งสัญญาณวิทยุ (ต้องถือ + กด PTT + ยกจ่อใกล้ปาก)
bool isGrabMet = !_requireGrab || _isGrabbed;
bool isPttMet = !_requirePttButton || _isPttPressed;
bool isProximityMet = !_requireMouthProximity;

if (_requireMouthProximity && _centerEyeAnchor != null) {
    // ตรวจสอบระยะห่างระหว่างตัววิทยุกับ HMD (Center Eye)
    float distToMouth = Vector3.Distance(transform.position, _centerEyeAnchor.position);
    isProximityMet = distToMouth <= _mouthProximityThreshold;
}

if (isGrabMet && isPttMet && isProximityMet) {
    _transmissionTimer += Time.deltaTime;
    if (_transmissionTimer >= _requiredTransmissionTime) {
        OnTransmissionCompleted?.Invoke(); // ส่งรายงานสำเร็จ
    }
}

3. Modular Triage Framework & VR Quality of Life

ออกแบบสถาปัตยกรรมแบบ Decoupled แยก Logic การประเมินเคสผู้ป่วยผ่าน TriageCase และรวบรวมรายงานด้วย TriageManager รองรับทั้งการแปะแท็กริบบิ้น (Snap Interactable), การส่งมอบอุปกรณ์ปฐมพยาบาล (Specific Item Filter) และการทำ CPR พร้อมระบบกันของหล่นหาย (InfiniteDispenser และ ToggleOnGrabOrSnap) วัตถุที่ปล่อยมือกลางอากาศจะเด้งกลับกระเป๋าอัตโนมัติ ทำให้ผู้เล่นในงานนิทรรศการเล่นได้อย่างลื่นไหล ไม่ต้องก้มเก็บของบนพื้น
