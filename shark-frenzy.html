Overview

เกมนี้เป็นเกมแนว Simulation Endless ตัวเกมจะจำลองผู้เล่นเป็นฉลามใต้ท้องทะเล โดยมีกลไกหลักคือความหิว (HP จะลดลงเรื่อยๆ ตลอดเวลาที่เริ่มเกม) ผู้เล่นจำเป็นต้องว่ายน้ำล่าปลาไปเรื่อยๆ เพื่อฟื้นฟู HP และทำคะแนน พร้อมหลบหลีกอุปสรรคอย่างระเบิดใต้น้ำ ผมได้รับหน้าที่ในการพัฒนา Core Gameplay System หลักทั้งหมด รวมถึงระบบเสียงและ Leaderboard ออนไลน์

Key Systems Developed

  • Player Movement: พัฒนาระบบควบคุมการว่ายน้ำของฉลามแบบ 3 มิติ (Omni-directional) ว่ายได้ทุกทิศทางด้วย Rigidbody Physics พร้อมระบบพุ่งตัว (Sprint) เร่งความเร็วเมื่อกด Shift
  • Stamina & UI: สร้างระบบ Stamina สำหรับพุ่งตัว โดยใช้ Coroutine ในการประมวลผล Delay ก่อนฟื้นฟูอัตโนมัติ พร้อมทำระบบ UI (StaminaBar/HealthBar) แยกออกมาและใช้ Mathf.Lerp ทำให้หลอดพลังงานไหลลื่นไม่กระตุก
  • Hunger System (HP): ดัดแปลงระบบเลือดให้เป็นความหิว เลือดจะลดลงอย่างต่อเนื่อง และลดเมื่อชนอุปสรรค (ระเบิด) ผู้เล่นต้องล่าปลาเพื่อเพิ่มเลือดกลับมา เป็น Game Loop ที่ช่วยกระตุ้นความตื่นตัว
  • Score & Backend: ทำระบบเก็บคะแนนเมื่อกินปลา และพัฒนาระบบ Leaderboard ระดับโลกโดยเชื่อมต่อกับฐานข้อมูลออนไลน์ (Backend Integration) ผ่าน Firebase API รวมถึงใช้ PlayerPrefs เป็นแผนสำรองบนเครื่อง
  • Audio System: ควบคุมระบบเสียงในเกม เช่น เสียงเพลงประกอบ, เสียงบรรยากาศใต้ทะเล, เสียงกัด, และเสียงระเบิด

Challenges & Solutions

การว่ายน้ำสามมิติ และระบบ UI แบบ Smooth: เพื่อให้การเคลื่อนที่ของฉลามตอบสนองทันที ผมเลือกใช้ ForceMode.VelocityChange ใน Rigidbody และเขียนตรรกะจำกัดความเร็ว (Velocity Clamping) เพื่อไม่ให้ฉลามพุ่งแรงจนหลุดการควบคุม

นอกจากนี้ การอัปเดต UI เช่นหลอดเลือดหรือ Stamina มักจะมีปัญหาตัวเลขกระโดดข้าม ทำให้ดูแข็งกระด้าง ผมจึงแยกส่วนประมวลผล UI ออกมาและใช้ Mathf.Lerp ร่วมกับ Time.deltaTime เพื่อให้หลอดลดหรือเพิ่มอย่างสมูธ

private void LimitSpeed() {
    // ดึงความเร็วแนวราบ (X, Z) ของ Rigidbody
    Vector3 flatVelocity = new Vector3(rb.linearVelocity.x, 0f, rb.linearVelocity.z);
    
    // จำกัดความเร็วไม่ให้เกิน moveSpeed
    if (flatVelocity.magnitude > moveSpeed) {
        Vector3 limitedVelocity = flatVelocity.normalized * moveSpeed;
        rb.linearVelocity = new Vector3(limitedVelocity.x, rb.linearVelocity.y, limitedVelocity.z);
    }
}

private void Update() {
    if (staminaSlider != null) {
        staminaSlider.value = Mathf.Lerp(staminaSlider.value, currentStamina, Time.deltaTime * smoothSpeed);
    }
}

// Stamina Regeneration with Delay using Coroutine
private IEnumerator RegenerateStaminaWithDelay() {
    isRegenerating = true;
    yield return new WaitForSeconds(regenDelay);
    
    while (currentStamina < maxStamina && canRegenerateStamina) {
        currentStamina += staminaRecoveryRate * Time.deltaTime;
        currentStamina = Mathf.Clamp(currentStamina, 0, maxStamina);
        yield return null;
    }
    
    isRegenerating = false;
}
