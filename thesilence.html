Overview

The Silence เป็นเกมแนว Horror Survival ที่เน้นเล่นกับความกลัว และความหลอนประสาทของผู้เล่น

My Role: ในโปรเจกต์นี้ผมรับหน้าที่เป็นผู้พัฒนาระบบหลักหลายส่วน ได้แก่ Player Movement, Interactive System, Inventory Hotbar, Flash Light, Camera System, Cutscene, และ Audio System

Key Systems Developed

  • Player Movement: ทำให้ผู้เล่นเคลื่อนไหวได้อย่างที่ควรจะเป็น (เดินหน้า ถอยหลัง ซ้าย ขวา) แบบ First-Person
  • Interactive System: ระบบที่ให้ผู้เล่นสามารถ Interact กับ Object หรือ Item ภายในฉากได้
  • Inventory Hotbar: ระบบเก็บ Item ภายในเกมและนำมาแสดงผลขึ้นบน Hotbar
  • Flash Light: สร้างระบบไฟฉายที่สามารถเปิด/ปิดได้
  • Camera System: จัดการมุมกล้องให้อยู่ในรูปแบบ First Person View อย่างสมบูรณ์
  • Cutscene: สร้างฉากคัตซีนเล่าเรื่องภายในเกม เช่น Intro Game
  • Audio System: ทำการออกแบบเสียงและมิกซ์เสียงภายในเกม (Sound Design) เช่น เสียงเดิน, เสียงเก็บ Item, และเสียงพากย์

Architecture & Mechanics

1. Player Prefab & FPS Camera

ผมได้แพ็ก Player เป็น Prefab เพื่อให้สะดวกต่อการนำไปใช้งานซ้ำใน Scene ต่างๆ โดยตั้งค่าให้ Main Camera เป็น Child ของ Player เพื่อบังคับมุมมองแบบ FPS (First-Person Shooter) ส่วนระบบ UI ต่างๆ (เช่น Health, Anxiety, SkillCheck) จะถูกรวมไว้ใน Canvas ที่ผูกกับตัวผู้เล่น

2. Puzzle System (Drag & Drop UI)

ระบบ Puzzle ภายในเกมถูกควบคุมด้วย 2 สคริปต์หลักคือ PuzzleManager และ PuzzlePiece โดยมีฟีเจอร์ที่สำคัญคือ:

  • Drag & Drop UI: โค้ดมีการใช้ Interfaces ของระบบ UI Unity (IBeginDragHandler, IDragHandler, IEndDragHandler) ทำให้ผู้เล่นสามารถใช้เมาส์คลิกค้างแล้วลากชิ้นส่วน (Image UI) ไปมาบนหน้าจอได้อย่างอิสระ
  • Canvas Scaling: ตอนลาก (OnDrag) มีการหารค่าด้วย canvas.scaleFactor ทำให้เวลาเอาเกมไปเปิดบนจอขนาดต่างๆ (Resolution ไม่เท่ากัน) เมาส์กับชิ้นส่วนก็ยังวิ่งตรงกันเป๊ะตามสัดส่วนจอ
  • Snapping Logic: เมื่อผู้เล่นปล่อยคลิกเมาส์ (OnEndDrag) ระบบจะเช็คระยะห่างระหว่าง "ตำแหน่งที่ปล่อย" กับ "ช่องเป้าหมายที่ถูกต้อง (correctSlot)" ถ้าอยู่ใกล้ในระยะ snapDistance ชิ้นส่วนนั้นจะ "ดูด" เข้าไปล็อคทันที (Snapping) แต่ถ้าปล่อยผิดที่ มันจะเด้งกลับไปจุดเริ่มต้นที่ลากมา
public void OnDrag(PointerEventData eventData)
{
    if (isPlaced) return;

    float scaleFactor = canvas != null ? canvas.scaleFactor : 1f;
    rectTransform.anchoredPosition += eventData.delta / scaleFactor;
}

3. QTE (Quick Time Event) / Skill Check System

ผมพัฒนาระบบ QTE ในรูปแบบหน้าปัดหมุน โดยคำนวณการเดินของเข็ม (Needle Rotation) เชิงคณิตศาสตร์ผ่าน Time.unscaledDeltaTime โค้ดถูกวางโครงสร้างด้วย Event-Driven คอยส่ง Event (OnSuccess / OnFail) ทำให้โมดูลนี้ทำงานเป็นอิสระ สามารถนำไปเชื่อมต่อกับระบบอื่นในเกม (เช่น ปลดล็อคประตู, ซ่อมของ) ได้ทันทีแบบ Decoupled System

นอกจากนี้ยังควบคุมการสุ่มขนาด (Size) และจุดเกิดเป้าหมายแบบไดนามิก รองรับการคำนวณข้ามเส้นวงกลม (360-degree Wrap-around Logic) ทำให้เป็นระบบสุ่มปฏิกิริยาที่ท้าทายผู้เล่น 

void CheckResult()
{
    float zoneEnd = zoneStart + zoneSize;
    bool success;

    if (zoneEnd <= 360f)
    {
        success = currentAngle >= zoneStart && currentAngle <= zoneEnd;
    }
    else
    {
        success = currentAngle >= zoneStart || currentAngle <= (zoneEnd % 360f);
    }

    if (success)
    {
        Debug.Log("SKILL CHECK: SUCCESS!");
        if (successSound != null && audioSource != null)
            audioSource.PlayOneShot(successSound, sfxVolume);
        OnSuccess?.Invoke();
    }
    else
    {
        Debug.Log("SKILL CHECK: FAIL!");
        if (failSound != null && audioSource != null)
            audioSource.PlayOneShot(failSound, sfxVolume);
        OnFail?.Invoke();
    }
}
